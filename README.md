# 🧭 CSS Navbar

A simple and clean **navigation bar project** created using **HTML and CSS**.
This project demonstrates how to create and style a navigation bar for a website.

## ✨ Features

* 🧭 Navigation bar
* 🔗 Navigation links
* 🎨 CSS styling
* 📐 Clean layout
* 🖱️ Hover effects
* 💻 Simple and beginner-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🚀 Live Website

https://zaidy7433.github.io/css-navbar/

## 🎯 Purpose

This project was created to practice **HTML navigation, CSS styling, links, spacing, and hover effects**.
